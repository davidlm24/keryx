**Anotações para os músicos**
- Escreva `// suave` numa linha da letra (ou `// 2x` no fim de uma linha): os músicos veem a anotação em itálico no Palco, no lugar onde ela foi escrita. A igreja nunca vê.
- No Editor de música, o botão **Anotação** (ao lado de Acorde) põe o `//` para você.
- Ajustes › Conteúdo tem o interruptor **Anotações**: ligado no Palco, desligado nas outras telas. A Cifra da Equipe no celular também mostra.
- `[Refrão]` continua sendo o nome da parte. Uma anotação escrita como `[SUAVE]` precisa virar `// suave`.
