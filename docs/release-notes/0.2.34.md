## O que mudou na 0.2.34

**Biblioteca para pedidos no GERAR**
- Se o GERAR ainda estava sendo atualizado quando o KERYX conectou, a biblioteca agora tenta publicar de novo automaticamente em até cinco minutos.
- Em Configurações › Conexões, com “Receber os pedidos” ligado, confira “Biblioteca no GERAR” para saber quantos itens foram publicados.
- Somente vídeos, áudios e links do YouTube da categoria **Louvor** ficam disponíveis para pedidos no GERAR. Seus arquivos e dados pessoais continuam somente neste computador.
